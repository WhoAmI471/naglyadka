# Наглядка — интерактивный каталог наглядных пособий

Next.js-реализация дизайна «Наглядка — каталог пособий» (Claude Design).
Каталог школьных наглядных пособий: предметы → пособия → интерактивная сцена
с ползунками, живым расчётом и формулами, которые пересчитываются на лету.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Приложение поднимется на http://localhost:3000.

Сборка и продакшен-запуск:

```bash
npm run build
```

```bash
npm start
```

Проверка типов:

```bash
npm run typecheck
```

## Что внутри

| Маршрут | Экран |
| --- | --- |
| `/` | Главная: hero, счётчики, карточки предметов |
| `/[subject]` | Пособия предмета с фильтром по типу |
| `/[subject]/[aid]` | Интерактивное пособие либо заглушка «в разработке» |

Дизайн описывал эти экраны как состояния одного SPA; здесь они разложены на
настоящие маршруты — ровно те, что дизайн сам генерирует в кнопке «Поделиться»
(`naglyadka.ru/physics/ballistics?v0=45&ang=45&g=9.8`). Ссылка теперь рабочая:
параметры из query подставляются в ползунки при загрузке страницы.

### Готовые интерактивы

* **Полёт ядра из ствола пушки** (`/physics/ballistics`) — парабола, вектор
  скорости, дальность/высота/время полёта.
* **Математический маятник** (`/physics/pendulum`) — период, частота,
  максимальная скорость, подъём груза.
* **Титрование кислоты щёлочью** (`/chemistry/titration`) — кривая pH, точка
  эквивалентности, бюретка и индикатор.

Остальные 10 пособий каталога отмечены значком «скоро» и открывают экран-заглушку —
как и задумано в дизайне.

## Структура

```
src/
  app/
    layout.tsx              корневой layout: язык и тема из cookie, шрифты, оболочка
    page.tsx                главная
    [subject]/page.tsx      список пособий предмета
    [subject]/[aid]/page.tsx интерактив или заглушка
    not-found.tsx           404 в стиле каталога
    globals.css             CSS-токены тем, слайдеры, анимации, hover-состояния
  components/               AppShell, Sidebar, Toast, Home/Subject/Aid/Stub, SimCanvas
  context/AppContext.tsx    язык, тема, тосты
  lib/
    data.ts                 предметы, пособия, «скоро»
    i18n.ts                 словари RU/EN и названия типов
    sims/                   ballistics, pendulum, titration + разбор query-параметров
    themes.ts               палитры для canvas (DOM берёт цвета из CSS-переменных)
    styles.ts               общие стили карточек, чипов, панелей
    format.ts               склонения, форматирование чисел, подписи на canvas
```

## Тема и язык

Тёмная/светлая тема и RU/EN хранятся в cookie (`nagl_theme`, `nagl_lang`), поэтому
сервер сразу рендерит нужный вариант — без мигания при загрузке. По умолчанию, как
в дизайне: тёмная тема и русский язык.

Цвета DOM живут в CSS-переменных (`globals.css`), а canvas получает те же цвета
конкретными значениями из `lib/themes.ts` — два списка нужно держать согласованными.

## Адаптивность

Раскладка вынесена из инлайн-стилей в классы `globals.css`, поэтому вся адаптация
живёт в одном месте.

| Ширина | Поведение |
| --- | --- |
| > 1600 px | контент центрируется, `max-width: 1600px` — строки не растягиваются |
| 1181–1600 px | исходный вид дизайна: рельс 248 px, поля 32 px |
| 981–1180 px | рельс сжимается до 216 px, поля 22 px |
| ≤ 980 px | рельс превращается в выезжающий drawer + верхняя панель с бургером |
| ≤ 620 px | одна колонка, кнопки пособия растягиваются на всю ширину |

Дополнительно:

* Сетки используют `minmax(min(310px, 100%), 1fr)` — карточка никогда не шире
  экрана и не вызывает горизонтальный скролл.
* Панель сцены и панель параметров задают `min-width: min(520px, 100%)`, поэтому
  колонки перестраиваются без отдельных медиазапросов.
* Высота canvas: 440 → 380 → 300 → 260 px по мере сужения экрана.
* Сами сцены знают про размер: в титровании бюретка рисуется только при
  ширине ≥ 560 px (иначе график занимает всё поле), у маятника длина нити
  ограничена высотой холста.
* Drawer закрывается по Esc, по клику на затемнение и при переходе по ссылке;
  `prefers-reduced-motion` отключает анимации входа и выезда.

## Отличия от исходного дизайна

* Состояния SPA разложены на маршруты Next.js (см. выше), навигация в сайдбаре —
  обычные ссылки.
* Добавлена адаптивная раскладка (в дизайне был единственный кадр 1440×940).
  На десктопе вид не меняется.
* В английском заголовке пособия по закону Ома используется типографский апостроф
  (`Ohm’s`).
